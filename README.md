# Electronics-Project-LFRSPC
LFRSPC is an Arduino-based robotic system designed to automatically clean solar panels by following a predefined path using line-following sensors. The robot enhances solar panel efficiency by removing dust and debris, combining automation with sustainable energy solutions. This project integrates sensors, motors, and control logic to create a low-cost, efficient cleaning solution for solar installations.

Key Features:

    Arduino Uno-based control system

    Line-following capability using IR sensors

    Cleaning mechanism integrated on the moving platform

    Power-efficient and eco-friendly

    Designed for small to medium solar panel setups

Tech Stack & Components:

    Arduino Uno

    IR Sensors (for line following)

    DC Motors with Motor Driver (L298N)

    Cleaning Brush or Wiper

    Battery Pack

    Chassis and wheels

    Optional: LDR, OLED display, or solar charging unit
